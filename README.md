# CareerConnect – Student Placement Portal

## About the Project
CareerConnect is a Student Placement Portal developed to help students find suitable placement opportunities according to their CGPA.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Company details and job roles
- Eligibility criteria based on CGPA
- Student application form
- Form validation
- Display of suitable companies
- Submission confirmation page

- index.html

- script.js
